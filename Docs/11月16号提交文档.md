## 二、攻击逻辑（改动详述）

**近战挥击态（ST_Sentinel / ST_AuditorStub 各加一态，零绑定自包含）：**

```
追击 --OnTick[目标距离≤200 (TargetInRange) + 距上次出招≥1.8s (AttackReady)]--> 攻击（中优先）
攻击：停移动 + SetFocus(目标) + PlayPrimaryAction + 写 AIC.LastAttackTime（冷却锚点）
      ↓ 0.35s（打击点）
      距离命中判定：目标 ≤220cm → [Attack] 挥击命中日志（玩家侧受伤由主角组接）
                  目标 >220cm → [Attack] 挥击落空（走位能躲）
      ↓ 动画播完
      回追击（冷却 1.8s 内不再进攻击态，怪追着绕位）
攻击 --EnemyLost--> 巡逻/待机（同追击语义）
```

- 新任务 `FStateTreeMeleeAttackTask`（StateTreeSentinelTasks.h/.cpp，与追击任务同文件，哨兵/审计官共用）
- 新条件 ×2（StateTreeEnemyConditions）：`TargetInRange`（进圈）、`AttackReady`（冷却转好，读 AIC.LastAttackTime）
- **冷却锚点放 AIC 而非任务**：任务实例数据随状态进出反复重建，放 AIC 才能跨状态记住"上次出招时刻"

**裁决者开火命中判定（StateTreeArbiterTasks）**：守盾警戒开火点加 `FireHitRange=1000cm`——射程（1200）内开火、命中距离（1000）内判中；超距落空有"极限射程擦弹"观感。命中只打日志（待玩家侧接伤害），与掠食者背刺同约定。

## 三、受击 / 血量 / 死亡底座（AIC 基类内置，四怪全通）

| 件 | 说明 |
| --- | --- |
| `Health`（float） | 资产烘焙：哨兵3/掠食者2/裁决者5/审计官4；**灰盒最小实现**，正式 Gameplay 血量系统定稿后迁移对接 |
| `TryReceiveHit(Attacker, HitRange=250, Damage=1)` | **蓝图可调**。距离击中判定：攻击者进圈即中（灰盒约定；正式弹道/投掷物由 Gameplay 层接管）→ 扣血 + 播受击动画；超圈只打 [Hurt] 未中日志。返回是否命中 |
| 受击动画 | `PlayHitReact()`（MM_Attack_03 替身，全员接入）；**攻击动作播到一半挨刀不顶掉攻击**——出招者不硬直 |
| `Die()`（Health≤0） | bDead → 停移动 + StateTree StopLogic + 感知回调早退（尸体不再"看见"人）→ 播 MM_Death_Front_01 冻末帧 → **留尸 5s**（CorpseLifespanSeconds）→ 销毁 Pawn + AIC |
| `bDebugAutoTakeHit` | 测试旗：玩家贴近 250cm 内自动每 1.5s 挨 1 刀。**哨兵资产默认开**——PIE 走近哨兵即可无代码验收 受击→死亡→留尸→销毁 全链路；玩家侧攻击就绪后关 |

## 六、已知偏差与剩余工作

**已知偏差**：
1. HP 是 AIC 灰盒最小实现——正式 Gameplay 层血量/伤害（框架侧）定稿后迁移对接，届时本层只留表现钩子（方案 §11.5 已注明）
2. 受击判定"进圈即中"，无视线检查——隔墙一刀也算中；玩家近战贴脸场景可接受，远程/弹道判定由 Gameplay 层接管后替换
3. 死亡留尸 5s 后直接销毁，无淡出（淡出需材质配合，正式版再定）
4. 哨兵 `bDebugAutoTakeHit` 资产默认开（演示/验收用）——**玩家侧攻击（徐泽铭侧）就绪后统一关掉**
5. 裁决者追杀态暂无近战攻击（贴身只追不打）——远程压制定位，是否补贴身补枪待跑数定（方案 §11.4 偏差④）
6. 攻击命中/开火命中/背刺命中现阶段全部只打日志（约定一致：玩家侧受伤表现由主角组接，真伤害事件等 Gameplay 层挂钩）
7. 本地 Content/XuTang/Animations 的 Mixamo 死亡动画（AS_Dying_Backwards 等，自研 retarget）未接入——引擎 MM_Death_Front_01 先顶灰盒，retarget 验证后可在 BP_AIC 直接换 DeathAnim

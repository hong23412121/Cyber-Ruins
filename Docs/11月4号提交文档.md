## 三、本轮踩坑沉淀（写给队友，均实测）

| # | 坑 | 结论 |
| --- | --- | --- |
| 1 | Mixamo 动画直接导到 SK_Mannequin → 头飞出去、脖子拉长 | Mixamo 骨架（mixamorig:*）与假人骨架 0 根同名，**必须走 IK Rig + IK Retargeter 重定向，不可直挂** |
| 2 | Sequencer 时间轴右键关键帧改"常量"没反应 | 5.8 引擎源码实锤：该菜单作用于【左侧轨道列表选中行的**全部**关键帧】，不是单颗帧。单点手术去**曲线编辑器**改；或用"同值对帧"——第 1 帧整列 Ctrl+C → 第 10 帧 Ctrl+V，两颗同值帧之间无论什么插值都恒定不变 |
| 3 | Output Log 看着全空 / 命令像没执行 | 小心开的是"**设备输出日志**"（手机调试窗口，永远空），真身是"输出日志"。实在不确定直接读 `Saved/Logs/CyberRuin.log`，所有命令与报错都在 |
| 4 | 引擎 5.8 的 Python 枚举名带前缀 | `unreal.FBXImportType.FBXIT_SKELETAL_MESH`（不是 SKELETAL_MESH）；跨版本写脚本用 hasattr 探测兜底 |
| 5 | 无头命令行跑项目脚本失败 | 先 `Get-Process UnrealEditor` 确认编辑器已关——两个引擎实例开同一项目会锁死 |
